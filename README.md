# Zadanie rekrutacyjne — code review

Cześć!

W ramach rozmowy chcielibyśmy zobaczyć, jak podchodzisz do code review.

## Co tu jest

W tym repo jest otwarty Pull Request, który dodaje obsługę webhooka z e-commerce
wystawiającego fakturę i wysyłającego ją do KSeF. Kod **funkcjonalnie działa** —
przechodzi happy path, ale ma swoje problemy.

## Co zrobić

1. Wejdź w zakładkę **Pull requests** i otwórz jedyny otwarty PR.
2. Zostaw komentarze inline (pod konkretnymi liniami) — tak, jakbyś robiła review
   koledze z zespołu.
3. Skup się na tym, co uważasz za istotne — nie ma "poprawnej" listy odpowiedzi.
   Interesuje nas Twoje podejście, priorytety i sposób argumentacji, nie ilość
   znalezionych uwag.

## Ile czasu

Około **30–45 minut**. Jeśli skończysz szybciej — super, jeśli wolniej — też ok,
nie limitujemy ściśle.

## Kontekst

Wyobraź sobie, że to fragment realnego systemu fakturowego. Sklepy internetowe
wysyłają webhook po opłaceniu zamówienia, my wystawiamy fakturę, wysyłamy ją do
KSeF i mailem do klienta.

Nie musisz znać dokładnie KSeF ani specyfiki bibliotek — chodzi o kod jako taki.

Powodzenia!
